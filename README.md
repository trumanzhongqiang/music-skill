# Music Skill 🎵

> 从一句情绪到一首完整的歌——为普通人准备的 AI 音乐创作流水线。

音乐创作不该只属于专业音乐人。普通人说不清「BPM 和调式」，但说得出「心碎但倔强」。Music Skill 接收一句情绪描述，自动走完一条完整的 AI 音乐创作链路：歌词 → 曲风 → MV → 分镜 → 视频。

## 功能特性

- **情绪是起点**：只需描述一种情绪或一个故事（如「夏夜雨后一个人散步的释然」），无需任何音乐术语
- **一条龙但可分步**：可以一键跑完全程，也可以只生成歌词、只设计 MV，随取随用，各阶段产物自包含
- **歌词创作**：基于情绪意象写作，控制押韵与结构（主歌/副歌/桥段），附自检清单
- **曲风提示词**：为 Suno 类音乐生成模型设计风格 Prompt（流派、节奏、配器、人声、情绪曲线），附 5 套常用流派模板
- **MV 概念设计**：整体视觉风格、色调、叙事主线、场景清单
- **分镜脚本**：逐镜头的画面描述、景别、运镜、时长，附分镜表模板
- **首尾帧提示词**：为每个分镜生成首帧/尾帧图像提示词，供图生视频模型使用
- **视频提示词**：首尾帧 + 运动描述，交给视频生成模型产出最终分镜片段
- **风格一致性**：歌词意象、曲风、MV 视觉共享同一份「情绪内核」，避免各说各话

## 快速开始

WorkBuddy 用户：

1. 下载本仓库中的 `music-skill.skill` 文件
2. 在 WorkBuddy 中加载该 .skill 文件
3. 说「启动原创音乐」+ 一句情绪描述，例如：

   > 启动原创音乐：夏夜雨后一个人散步的释然

也可以只调用其中一环：

> 帮我写首歌词：心碎但倔强，不要苦情，要有骨气

## 工作方式

```
情绪描述
  → 情绪解析与风格锚定（情绪对 / 核心意象 / 能量曲线 / 风格锚定句）
  → 歌词（主歌/副歌/桥段，押韵与意象纪律）
  → 曲风提示词（Suno 类模型）
  → MV 概念（视觉风格 / 叙事主线 / 场景清单）
  → 分镜脚本（逐镜头：景别 / 运镜 / 时长）
  → 首尾帧提示词（图生视频模型）
  → 视频提示词（视频生成模型）
```

所有产出均为可直接粘贴到对应生成工具的提示词或文档；Skill 本身不生成音频/视频文件。
