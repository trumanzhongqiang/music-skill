# 曲风提示词（Suno 类模型）

> 锚定句：2020s 都市轻民谣流行，办公室下午三点的慵懒吐槽
> 模型缺口声明：未指定目标模型版本，按 Suno v4 主流英文格式产出。

## Style Prompt（可直接粘贴）

```
chinese indie folk pop, 2020s shanghai office comedy, 88-94 bpm, 4/4,
fingerpicked acoustic guitar and lazy brushed drums, warm upright bass,
glockenspiel hooks, playful melodica solo after the second chorus,
relaxed half-spoken male vocal, gang vocal chants on chorus,
drowsy verse building to a tongue-in-cheek anthemic chorus, quiet resigned outro
```

## 中文说明（五要素对照）

| 要素 | 内容 |
|------|------|
| 流派 | chinese indie folk pop（1 个主标签 + 年代场景参照） |
| 年代/地域参照 | 2020s shanghai office comedy（都市打工人喜剧感） |
| 节奏 | 88-94 bpm, 4/4（慵懒但不拖沓） |
| 配器 | 指弹木吉他 + 慵懒鼓刷打底，钟琴点缀俏皮，第二遍副歌后口风琴 solo，配器逐步进入 |
| 人声与情绪曲线 | 半说半唱的松弛男声，副歌众人合唱（吐槽变呐喊）；困倦主歌 → 自嘲式 anthem 副歌 → 安静认命的尾奏，与情绪内核的能量曲线一致 |

## Exclude（本次回补）

初版只写了想要的声音，没写忌讳。按后来补上的规则，粘贴时把下面一行接在 Style Prompt 后面：

```
exclude: heavy auto-tune, EDM drop, trap 808, metal distortion, operatic vocal
```

这是办公室自嘲，不是电音或史诗。不写排除项时，模型容易默认加电音处理。
