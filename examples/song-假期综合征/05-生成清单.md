# 生成清单

> 镜头 001~012：图像提示词 × 2（首帧/尾帧），视频提示词 × 1（见 04-分镜脚本.md 各镜头条目）
> Suno style prompt × 1（见 02-曲风提示词.md）
> 歌词（带结构标注）× 1（见 01-歌词.md）

## 使用顺序建议

1. 歌词 + style prompt → Suno 生成歌曲，选出满意版本
2. 逐镜头：首帧/尾帧提示词 → 图像模型出帧；确认两帧主体一致后再进下一步
3. 首帧 + 尾帧 + motion → 视频生成模型出 12 段素材
4. 按分镜表时长剪辑，副歌段（008-010）切换更快

## 待确认缺口

- Suno 目标版本未指定（按 v4 主流格式产出）
- 视频生成模型未指定（motion 按主流英文格式产出）
- 片长按 1 分钟短版执行；若需完整 3~4 分钟版，分镜需扩至 30~50 镜并重跑质检
