# 中文韵脚库（rhyme-library）

阶段 1 歌词创作的选韵与押韵参考。原则：**先定情绪再选韵**，全首统一一个韵脚，副歌必须句句押韵。

## 一、选韵总则

- **开口韵响亮**（ang / an / ao / ai）：尾音口腔张开，适合呐喊、副歌高潮、励志与吐槽向
- **闭口韵内敛**（i / ü / u / eng）：尾音收拢，适合低语、抒情、深夜独白
- **平声绵长，仄声短促**：平声韵（ang/eng/ong）拖得长，适合抒情；仄声收尾干脆，适合说唱感与态度表达
- **副歌换开口度**：主歌可用略收的韵铺陈，但全首韵脚不变——靠句式长短而非换韵制造对比

## 三、避坑

- **生僻字凑韵**：为了押韵用「霑」「昒」这类没人念的字，唱出来听众直接出戏——韵脚字必须是口语高频字
- **同字押韵**：相邻两行用同一个字收尾（「上班/下班」连用两次以上），听起来像词穷——同字最多出现一次，且最好隔段
- **韵脚漂移**：主歌押 an、副歌滑到 ang，听感上像两首歌——全首锁死一个韵脚，写不下去换词不换韵
- **强凑毁句**：「我要去上班的班」这种为了押韵把句子拧断的写法，宁可这行不押也要保句子通顺——但副歌不适用此豁免，副歌句句必押

## 四、副歌 Hook 写法

- 副歌第一句放全曲最容易记住的短句（≤10 字），最好能在第 40 秒内出现一次
- Hook 句型优先「重复 + 微变」：如「我不想上班 不想上班」——重复建立记忆，微变推进情绪
- 末字优先选开口度大的韵字（班/光/笑），方便歌手拉开长音
