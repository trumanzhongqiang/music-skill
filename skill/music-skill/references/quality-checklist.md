# 质检四查（交付前必过）

发布任何阶段产物前，逐查执行。每查必须产出明确结论——「过 / 不过 + 问题定位」，禁止「基本没问题」这类模糊判断。四查全部通过才可交付；任何一查不过，按文末「复查纪律」回到对应阶段修复。

## 什么时候跑

- **全链路交付**（一次跑完阶段 0~6）：四查按顺序全跑，从第一查开始。
- **单环节交付**（用户只要歌词 / 只要分镜等）：只跑与该环节相关的查——只要歌词跑第三查 + 第一查的歌词部分；只要分镜跑第四查 + 第一查的画面部分；曲风、首尾帧、视频提示词跑第二查。
- **增量续作**（用户已有歌词/曲风，从中间环节接入）：先确认已有产物的情绪锚可查（第一查），再跑后续相关查。若用户提供的上游产物找不到情绪锚，点名这个缺口（「这份歌词里没有可供锚定的情绪内核」），问用户要一句锚定描述，不要自己瞎猜。

## 第一查：情绪锚定（全链路是否共享同一情绪内核）

**怎么看**

1. 打开 `00-情绪内核.md`，确认四字段齐全：情绪对（含反差）、核心意象 2~3 个、能量曲线（标了副歌位置）、风格锚定句。
2. 逐阶段做「锚定句比对」：歌词、曲风提示词、MV 概念、分镜表每个阶段的标题下方，是否都引用了同一份情绪内核（情绪对 / 锚定句）？
3. 意象溯源：从歌词里随机抽 5 个画面性词汇，逐个问「它是不是核心意象或其自然延伸？」——出现核心意象之外的新意象（比如内核定的是「路灯、影子」，歌词里冒出「海浪」），即为漂移。
4. 情绪词比对：曲风提示词的 mood/energy 描述、MV 概念的色调与光线、分镜的情绪标注，三者用词是否指向同一个情绪对？（例：内核是「释然 × 怅惘」，曲风却写 anthemic cathartic，即打架。）

**过了长什么样**

- 任一阶段单独拎出来看，不看其他文件也能说出同一个情绪对；把四个阶段的产出并排放在一页上，没有一处情绪词互相矛盾；歌词、画面、编曲的能量走向与阶段 0 的能量曲线同形状。

---

## 第二查：提示词可执行（模型拿到就能用）

**怎么看**

1. **Suno 曲风提示词五要素逐一点名**：流派标签、年代/地域参照、BPM 范围 + 拍号、配器（4~6 件且标注进入时机）、人声 + 情绪曲线。缺一个就判不过。
2. **粘贴测试**：把曲风提示词原样复制一遍——是否全英文、无中文夹杂、无「可适当调整」「偏 XX 一点」这类写给人看的废话？有即不过。
3. **流派标签计数**：超过 2 个标签即不过（如 `pop rock electronic folk`）。
4. **首尾帧格式**：随机抽 3 个镜头，首帧/尾帧提示词是否都含主体与动作、环境、光线、色调与质感、镜头参数五段？是否逐字复用统一风格后缀？主体外观描述（年龄感、服装、发型）跨镜头是否一致？
5. **首尾帧差异审计**：逐字 diff 同一镜头的首帧与尾帧——差异处是否只有「动作发展」？主体、场景、光线、色调、镜头参数任何一处变了即不过。
6. **视频提示词**：运动描述是否一句话、只写「谁动了、怎么动、镜头怎么动」？运镜是否与分镜表「运镜」字段一致（表写推、prompt 就写 push in）？
7. **模型缺口声明**：若用户未说明目标模型版本，产出中是否已点名该缺口并声明默认格式？未声明即不过。

**过了长什么样**

- 每段提示词都不需要二次编辑即可粘进对应工具；同一镜头的首尾帧 diff 干净到只剩动作词；整支 MV 所有镜头共用同一段风格后缀，像同一个人写的。

---

## 第三查：文字清晰（歌词经得起细看）

**怎么看**

1. **错字与顺口度**：把歌词从头念一遍出声（默念即可），卡壳、歧义、错别字的句子逐个标出；改到每句一念就顺。
2. **押韵审计**：标出每行末字拼音，确认整首同一韵脚；副歌逐句核对——副歌有任何一句不押韵即不过。
3. **结构完整性**：段结构标注齐全（[主歌 1] [副歌] …），主歌 1 → 副歌 → 主歌 2 → 副歌 → 桥段 → 尾副歌的骨架不缺段；用户要求精简时可缺预副歌，但主歌/副歌/桥段不可缺。
4. **抽象词扫描**：逐句找「很难过」「很孤独」式抽象表达，每处必须能指认一个替代画面；指认不出即回改。
5. **路人测试**：副歌任意一句单独拎出来给「不看全词的人」看，对方能说清这首歌在唱什么——说不清即不过。
6. **字数抽查**：主歌每行 8~12 字、副歌每行 6~10 字，各抽 3 行核对，超出范围即不过。

**过了长什么样**

- 歌词没有一句需要读者猜；副歌句句押韵且比主歌短；任意一段单独读都有画面、不依赖上下文解释。

---

## 第四查：节奏（曲线有起伏、镜头可拍、高潮落对位置）

**怎么看**

1. **情绪曲线形状**：把阶段 0 的能量曲线和歌词段落排在一起——全曲是否有「平静 → 抬升 → 爆发/回落」的起伏？从头平到尾即不过。
2. **高潮落点**：最大能量（编曲最满、镜头最密、情绪最高的一句）是否落在副歌？落在主歌或桥段即不过。
3. **桥段转折**：桥段是否与主歌视角不同（时间、人称、空间至少换一个）？没有换即不过。
4. **镜头节奏对照**：分镜表中副歌段镜头时长是否整体短于主歌段？相邻镜头时长差是否 ≤1 秒（副歌段）？抽副歌段 5 个连续镜头核对。
5. **可拍性抽查**：随机抽 5 个镜头的画面描述——每个镜头是否一句话能拍（有明确主体、动作、环境、光线）？出现「情绪弥漫」「意识流」式拍不出来的描述即不过。
6. **镜头量核对**：3~4 分钟 MV 为 30~50 镜，1 分钟短版为 10~15 镜，明显不足或溢出即不过。
7. **总时长验算**：分镜表所有镜头时长相加，是否覆盖目标片长（±15%）？差太多说明拆镜密度错。

**过了长什么样**

- 只看分镜表的时长列就能感到「副歌处变密、主歌处放缓」；每个镜头交给一个不懂这首歌的摄影师也能直接拍；全曲听完有记忆峰值，且峰值在副歌。

## 复查纪律（结构问责）

- 每查结束必须写出结论，格式固定为：**「第 X 查：过 / 不过；问题：〈具体位置 + 现象〉」**。写不出具体位置的问题视为没查到，重查。
- 问题必须回阶段修，不许就地糊补：

| 问题类型 | 回哪个阶段 |
|----------|-----------|
| 情绪词矛盾、意象漂移、锚定句缺失 | 阶段 0 复核内核，再回矛盾所在阶段重出 |
| 曲风五要素缺失、流派超标签、中英文混杂 | 阶段 2 重出曲风提示词 |
| 首尾帧差异越界、风格后缀不一致 | 阶段 5 重出该镜头帧提示词 |
| 运镜与分镜表不一致、运动描述超一句 | 阶段 6 重出该镜头视频提示词 |
| 押韵不达标、抽象词、错字、结构缺段 | 阶段 1 重出歌词（改后重跑第一查） |
| 镜头不可拍、时长密度错、高潮落点错 | 阶段 4 重排分镜（改后重跑第四查） |

- 修复后从对应查开始**重跑全部四查**，不允许「只复查改过的那一条」——下游产物都是基于上游产出的，上游一变，下游一致性必须重新确认。
- 四查全部通过后，才能进入交付目录打包。

## 四查速记

| 查 | 一句话 | 核心动作 |
|----|--------|----------|
| 一、情绪锚定 | 全链路是否同一情绪内核 | 锚定句比对 + 意象溯源 + 情绪词比对 |
| 二、提示词可执行 | 模型拿到能否直接用 | 五要素点名 + 首尾帧 diff + 粘贴测试 |
| 三、文字清晰 | 歌词经得起细看吗 | 念一遍 + 韵脚标注 + 路人测试 |
| 四、节奏 | 曲线起伏、高潮落副歌、镜头可拍 | 时长列扫密疏 + 高潮落点 + 可拍性抽查 |

任何一查处拿不准「过不过」时，判不过——回阶段修的成本远低于用户拿着废提示词去生成工具里试错。
